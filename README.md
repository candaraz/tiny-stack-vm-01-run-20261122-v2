# tiny-stack-vm-01

A tiny stack VM for [make.fun](https://make.fun/c/tiny-stack-vm-01-run-20261122): `main.ts` (Node 22, no dependencies) runs every program of a set and writes its output bytes and exit code, implementing the ISA exactly.
